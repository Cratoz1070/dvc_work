# Titanic — воспроизводимая лабораторная с DVC

Задача работы — предсказать, выжил ли пассажир «Титаника», и проверить, улучшают ли дополнительные признаки качество классификации. Из исходного ноутбука вынесены предобработка, обучение и оценка случайного леса. DVC связывает версию датасета, настройки и результаты каждого запуска.

## Что было сделано

1. Обучающий набор Kaggle Titanic (`train.csv`, 891 пассажир) добавлен под контроль DVC. Его хеш хранится в [`data/train.csv.dvc`](data/train.csv.dvc).
2. В [`train.py`](train.py) перенесён случайный лес из лабораторной. Он оценивается на пяти одинаковых для обоих экспериментов стратифицированных фолдах. Все настройки, которые зависят от данных, вычисляются по обучающей части каждого фолда.
3. В [`params.yaml`](params.yaml) вынесены параметры, а в [`dvc.yaml`](dvc.yaml) описан этап `evaluate` и три графика. [`dvc.lock`](dvc.lock) фиксирует состояние последнего выполненного этапа.
4. Выполнены два эксперимента. `baseline` использует базовые признаки. `extended` добавляет обращение из имени, семейные, возрастные признаки и признаки каюты. В обоих вариантах возраст заполняется медианой, а параметры леса и проверочные фолды одинаковы.

## Результаты

Метрики в таблице — средние по пяти проверочным фолдам.

| Эксперимент | Accuracy | F1 по выжившим | ROC-AUC |
| --- | ---: | ---: | ---: |
| `baseline` | 83,39% | 75,86% | 0,87245 |
| `extended` | 83,95% | 78,10% | 0,87283 |

Расширенный набор дал **+0,56 п. п. Accuracy и +2,24 п. п. F1**. При этом ROC-AUC почти не изменился. При стандартном выборе класса модель нашла на 23 выживших больше (`233 → 256`), но добавила 18 ложных предсказаний выживания (`39 → 57`). По графику важности, перемешивание `Sex` снижало Accuracy расширенной модели примерно на 10,01 п. п., а перемешивание `Title` — на 5,16 п. п.

## Как запустить в Windows

Понадобятся Git, Python 3.13 и DVC. Откройте корень репозитория в VS Code и запустите PowerShell. При первой установке зависимостей выполните:

```powershell
py -3.13 -m pip install -r requirements.txt
dvc version
```

Первая команда устанавливает версии библиотек, указанные в [`requirements.txt`](requirements.txt). Вторая проверяет, что `dvc` доступен в терминале. Этап запускает `py -3.13 train.py`, поэтому пакеты должны быть доступны именно этому Python.

Поместите исходный `train.csv` из [соревнования Titanic на Kaggle](https://www.kaggle.com/competitions/titanic/data) в папку `data`. Нужен файл с целевым столбцом `Survived`. В репозитории публикуется `.dvc`-файл с метаданными, а исходный CSV добавлен в `data/.gitignore`. В текущей конфигурации отдельное DVC-хранилище не настроено.

```powershell
dvc repro
Get-Content .\evaluation\metrics.json
```

`dvc repro` проверяет входы, настройки и выходы. Он запускает `evaluate`, если результаты отсутствуют или этап устарел. `Get-Content` показывает итоговые метрики. Для принудительного повторного обучения с текущими параметрами используйте `dvc repro --force evaluate`.

## Как повторить сравнение

Из корня репозитория запустите эксперименты с именами, которые ещё не заняты в вашей копии:

```powershell
dvc exp run -n baseline -S 'features=baseline'
dvc exp run -n extended -S 'features=extended'
dvc exp show
```

Первые две команды обучат модель с разными наборами признаков и сохранят результаты под именами `baseline` и `extended`. `dvc exp show` откроет таблицу параметров и метрик. После запуска `extended` в рабочей папке будут его результаты. Если эти эксперименты уже видны в таблице, можно сразу перейти к просмотру графиков.

В **VS Code** установите [DVC by lakeFS](https://marketplace.visualstudio.com/items?itemName=lakeFS.lakefs-dvc). Через `Ctrl+Shift+P` откройте `DVC: Show Experiments`, отметьте оба эксперимента в таблице и выполните `DVC: Show Plots`. Сравните ROC-кривые, матрицы ошибок и важность признаков. [Сравнение экспериментов в DVC](https://doc.dvc.org/user-guide/experiment-management/comparing-experiments#compare-plots)

Из **PowerShell** то же сравнение можно открыть в браузере:

```powershell
dvc plots diff baseline extended --out .dvc/tmp/titanic-plots
Invoke-Item .\.dvc\tmp\titanic-plots\index.html
```

Для графиков только по текущей папке используйте `dvc plots show --out .dvc/tmp/titanic-plots`. Обычный `git push` публикует коммиты ветки. Эксперименты DVC хранятся локально, пока их не отправят отдельно, поэтому в новом клоне их можно повторить командами выше.
